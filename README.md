# x-ui-yg 一键部署入口（A / B 方案）

本项目是对 [yonggekkk/x-ui-yg](https://github.com/yonggekkk/x-ui-yg) 官方安装脚本的**自动应答封装层**。

它**不修改**上游 `install.sh` 的任何安装逻辑和核心函数（`serinstall()`、`userinstall()` 等），只是在运行时自动把交互式问答（选菜单、设用户名/密码/端口/路径、是否关防火墙等）用预设答案替官方脚本回答一遍，从而实现“一键跑完”，不用人工守在终端一步步输入。

---

## 这个脚本做了什么

1. **安全前置检查**
   - 必须用 `root` 运行。
   - 检测到系统已安装过 x-ui（存在 `/usr/local/x-ui/x-ui`、`x-ui.service` 等）时直接退出，**不会覆盖已有安装**。只适合全新 VPS。

2. **两种部署模式**

   | 模式 | 用户名 | 密码 | 端口 | 路径 |
   |---|---|---|---|---|
   | **A（全自动，默认）** | zulpo | zulpo | 固定 8843 | zulpo |
   | **B（自定义端口）** | zulpo | zulpo | 你手动输入（1-65535） | zulpo |

3. **端口占用预检查**：用 `ss` 提前判断端口是否被占用，占用则直接退出，不会跑一半才失败。

4. **下载并校验上游脚本**：从 `raw.githubusercontent.com` 拉取官方 `install.sh`，校验文件非空、关键函数存在、脚本结构（最后一行是否为 `show_menu`）没有发生变化，避免上游改版后自动化逻辑误判出错。

5. **追加自动应答层**：在上游脚本末尾追加一段 `readp()` 覆盖函数，按提示词关键字自动匹配并回答：
   - 主菜单 → 自动选"1"（一键安装），装完后再弹菜单就自动选"0"（退出）
   - **是否关闭防火墙/清空 iptables** → 固定回答"2"（跳过，不关防火墙），避免误清空安全规则
   - 用户名 / 密码 / 路径 → 固定 `zulpo`
   - 端口 → 你在 A/B 模式里选定的值
   - 登录方式（是否启用证书）→ 直接回车，保持 HTTP
   - 遇到**未预料到的提示**，不会瞎猜答案，而是打印出来交还给你手动输入，保证安全

6. **执行安装**：实际运行改写后的脚本，完整走一遍上游安装 → 配置账号端口的流程，并把退出码透传出来，方便判断装没装成功。

## ⚠️ 使用前必读

- **默认账号密码是弱密码 `zulpo` / `zulpo`**，装完后请**立刻**在面板里改掉，否则公网暴露存在被猜测/爆破的风险。
- 脚本**不会**帮你关闭防火墙或开放端口，你需要自己确认：
  - VPS 自身防火墙（ufw / firewalld / iptables）放行所选端口
  - 云服务商的安全组 / 防火墙规则放行该端口的 TCP 入站
- 本脚本只适配**全新、未装过 x-ui 的 VPS**，老环境请先自行清理或手动安装。
- 该面板类工具通常用于代理/VPN 场景，部署与使用请确认符合你所在地区的法律法规。

## 怎么使用

### 方式一：直接用 curl 一键拉取运行（推荐）

在全新 VPS 上用 root 执行：

```bash
curl -fsSL https://raw.githubusercontent.com/Forlorn-zulpo/yjainbusx-ui/main/install.sh -o install.sh
chmod +x install.sh
sudo bash install.sh
```

或者一行命令（不落盘，直接管道执行 — 仅在你完全信任脚本来源时使用）：

```bash
curl -fsSL https://raw.githubusercontent.com/Forlorn-zulpo/yjainbusx-ui/main/install.sh | sudo bash
```

### 方式二：手动下载再运行

```bash
wget -O install.sh https://raw.githubusercontent.com/Forlorn-zulpo/yjainbusx-ui/main/install.sh
chmod +x install.sh
sudo ./install.sh
```

### 运行过程中你会看到

```
==============================================
       x-ui-yg 一键部署（A / B 方案）
==============================================
A. 全自动：用户名 zulpo，密码 zulpo，端口 8843，路径 zulpo
B. 自定义端口：用户名 zulpo，密码 zulpo，路径 zulpo
请选择 A 或 B [默认 A]：
```

- 直接回车或输入 `A`：走全自动流程，端口固定 8843。
- 输入 `B`：会继续提示你输入自定义端口号（1-65535）。

之后脚本会自动下载官方安装程序、做依赖检查、安装并启动 x-ui 服务，全程无需你手动输入账号密码等信息（除非遇到脚本未预设的提示）。

### 安装完成后

脚本结束时会提示"上游安装流程已结束"，你需要：

1. 往上翻看输出日志，确认 x-ui 服务状态（通常会打印访问地址，形如 `http://你的IP:端口/路径`）。
2. 确认防火墙/安全组已放行所选端口。
3. **登录面板后立刻修改默认用户名密码**。
4. 可选：如果需要启用 HTTPS/证书登录，回到面板里自行配置（脚本安装阶段默认跳过，保持 HTTP）。

## 常见问题

**Q: 为什么选项 B 还要我手动输端口，不能也自动吗？**
A: 自动模式下大部分人更想要稳定可预期的部署方式；B 方案是留给需要自定义端口、但仍不想手动过一遍交互问答的人。

**Q: 脚本提示"自定义端口被判定占用"直接退出了怎么办？**
A: 说明你选的端口已经被其他进程占用，换一个端口重新执行脚本即可（`ss -lntup | grep 端口号` 可以自查）。

**Q: 上游仓库更新了，这个脚本还能用吗？**
A: 脚本内置了对上游结构的校验（函数是否存在、脚本结尾是否仍是 `show_menu`），如果上游改动较大导致校验不通过，脚本会直接报错退出而不是盲目尝试，此时需要人工检查上游变化后更新本脚本的 `case` 匹配规则。

**Q: 能不能改默认用户名密码/端口？**
A: 可以，直接编辑脚本开头的 `USERNAME` / `PASSWORD` / `PATH_VALUE` 变量，或者走 B 模式自定义端口。
